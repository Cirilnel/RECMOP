## Overview

RECMOP is a powerful developer tool designed to streamline geospatial data processing and analysis for renewable energy and environmental projects. Its core features include:

* 🔵 **Accurate Policy Calculations:** Utility functions that handle CRS transformations to ensure precise area measurements across datasets.
* ☀️ **Integrated Energy Workflows:** Supports demand calculation, solar production estimation, and spatial modeling for energy communities.
* 🌎 **Robust Data Handling:** Facilitates processing of diverse geospatial formats like GeoPackage, shapefiles, and more, enabling seamless data integration.
* 📊 **Automated Reporting:** Generates comprehensive spatial reports and models to support decision-making and project assessments.
* 🌳 **Environmental Data Support:** Incorporates legal, climatic, and cadastral data for holistic environmental and land use analysis. RECMOP empowers developers to efficiently manage complex geospatial workflows, ensuring reliable measurements, insightful modeling, and impactful analysis in sustainability initiatives.

## Getting Started

### Prerequisites

This project requires **Python** and the following dependencies:

* `beautifulsoup4==4.14.2`
* `dbfread==2.0.7`
* `geopandas==1.0.1`
* `grass==0.1.2`
* `numpy==2.3.4`
* `osgeo==0.0.1`
* `pandas==2.3.3`
* `playwright==1.52.0`
* `pvlib==0.13.0`
* `python-dotenv==1.2.1`
* `rapidfuzz==3.14.3`
* `rasterio==1.4.3`
* `rasterstats==0.20.0`
* `Requests==2.32.5`
* `tabulate==0.9.0`

### Installation

Build RECMOP from the source and install dependencies:

1.  Clone the repository:
    > `git clone https://github.com/saldm04/RECMOP`

2.  Navigate to the project directory:
    > `cd RECMOP`

3.  Install the dependencies using `pip`:
    ```bash
    pip install -r requirements.txt
    ```
